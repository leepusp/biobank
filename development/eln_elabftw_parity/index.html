    B3 ELN — parity checklist with eLabFTW

    Source studied: elabftw/elabftw master e60e66b (2 Nov 2026), read for behaviour only. eLabFTW is AGPL-3.0: no code is copied; every feature below is reimplemented in Django. The client libraries eLabFTW builds on are permissively licensed and may be used directly:

    Library Licence Used for
    TinyMCE 6.8.x (last MIT line) MIT main rich-text editor (menus, tables, templates)
    jspreadsheet-ce 5 MIT spreadsheet with formulas inside entries
    FullCalendar 6 MIT scheduler / Lab Calendar
    Ketcher 3 Apache-2.0 chemical structure editor
    3Dmol.js 2 BSD-3 molecule / structure viewer
    jsoneditor 10 Apache-2.0 metadata JSON editor

    B3-only modules stay where eLabFTW has no equivalent: Biobank inventory (samples, collections, shipments), Molecular Registry, Jupyter/Slurm, workflows/Galaxy, ENA/NCBI/Zenodo submission.

    Status: ✅ done · 🟡 partial · ⬜ to do. Release = planned B3 Bench release.

    The classic notebook page was retired in 2.1; old links redirect to the entry page. The separate "Private drafts" store was retired in 2.1.1: private work is an entry with visibility Private. Draft files already written to a user's home are left untouched.
